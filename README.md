**Stock Monitering Application**

A web-based stock trading application that mimics the functionalities of the Zerodha trading platform. Designed for both novice and experienced traders, this application provides real-time market data, user-friendly interfaces, and essential trading features to facilitate seamless stock trading.

**Features**

**User Authentication**: Secure sign-up and login system to manage user accounts and trading sessions.

**Market Data**: Access to live stock prices, charts, and market updates.

**Stock**: Users can buy and sell stocks with real-time order execution.

**Portfolio**: View and manage user portfolios, including current holdings and historical performance.

**Market Analysis**: Tools for technical analysis, including charts and indicators.

**Watchlist**: Customizable watchlists to track favorite stocks and receive updates.

**Order Types**: Support for various order types, including market orders, limit orders, and stop-loss orders.


**Technologies Used**

**Frontend**: React.js, BootStrap, Chart.js (for charts)

**Backend**: Node.js, Express.js

**Database**: MongoDB
